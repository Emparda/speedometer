# Версия 1.1.1

Исправлена структура телефонной страницы: каждый текстовый элемент помещён в отдельный блочный контейнер; дата, статус, скорость, расстояние, время, поля и кнопки разделены. Убрано дублирование названия в заголовке, сокращено пояснение синхронизации. Логика записи и интерфейс часов не изменены. Версия 1.1.1, code 3.

Шесть тестов истории и действий телефонной страницы прошли. Внешний вид именно в Zepp после исправления ещё не проверен, тесты используют заглушки компонентов.

Приложение, установленное через zeus preview, в пользовательской версии Zepp доступно через Developer Mode → Mini Program → Settings. В проекте нет подтверждённого способа поместить его в сетку «Настройки приложений на устройстве». Размещение управляется Zepp. Официальная публикация через магазин требует регистрации приложения и проверки: https://docs.zepp.com/docs/distribute/ . Даже публикация не является обещанием появления именно в желаемой сетке.

Для установки распакуйте полный архив в новую папку и запустите Обновить.cmd. Для GitHub загрузите содержимое Speedometer с сохранением структуры. Не удаляйте установленное приложение ради изменения расположения: это не подтверждённый способ переноса и может стереть данные.
